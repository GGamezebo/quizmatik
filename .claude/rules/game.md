# Game scene / battle

## Ownership

- Orchestration: `game.gd` resolves scenario → `ResourceUtils.update_resource` into live `GameConfig`
- Live `game_config.tres` on the scene = **standalone defaults** (scene must run alone); parent overrides via `ev_start_game` → `initialize(data)`
- States: `GameManager` FSM only (`CountDown` / `Game` / `EndGame`). `CountDownState`: emits `ev_countdown_entered`, starts the plane fly-in deferred unless held (`ev_hold_countdown`), then `ev_countdown_started` (HUD `ui/timed_intro.gd` pops on it); plane hidden while held
- Round: `round/round_controller.gd`, `answer_spawner.gd`, `combat_resolver.gd`
- Questions: `question_generator.gd` (`QuizQuestion`)
- Features: spawn/compose from `src/features/` — keep feature logic inside the feature; scene only wires and reacts to `ev_*`

## Change guide

| Spawn layout / lanes | `GameArea` + `AnswerSpawner`; window resize → `GameArea.boundary_changed(rect)` → `LineSelector` (plane lanes) + `GameState` (`Answer.refit`, `ev_lanes_changed`) — never cache lane rects / viewport size |
| Question math | `QuizQuestion` + `GameConfig` fields (ops +, −, ×, ÷, `SQUARE` 16 «n² = ?», `ROOT` 32 «√(n²) = ?» — operand range = n, fact `mul:n:n`, never hidden operand, `_build_power_question`): `_pick_random` retries (`PICK_ATTEMPTS`) until `_fits` (result range, carry, minuend ≥ subtrahend); +/× shown in random order; `RoundController` passes previous `fact_key` → no same example twice in a row; hidden operand `? + 3 = 7` via `missing_operand_chance` gated by `missing_operand_start_progress` (`missing_operand_chance_at(score)`; `RoundController` passes `player.score`) (`_hide_operand` / `_fill_close_options`) |
| Wrong options | +/−: `_generate_close_fake_add_sub` (±1–3, operand ±1, ±10 once two-digit); ×/÷: `_generate_plausible_fake` (table neighbours, ±1–2, ±10, `a+b`; × keeps only within `max(3, correct/2)`; ÷ = quotient ±1–3 + divisor). Never random ranges (kids guess by size) |
| Weak-example review | Every `Question` has `fact_key` (`MathFact`: `add:x:y` covers +/−, `mul:x:y` covers ×/÷). `GameConfig.review_facts` (runtime, from payload `review_facts` set in `game.gd`) + `review_chance`: `_pick_review` re-asks a weighted fact only via allowed ops inside the op's 1st/2nd operand ranges + `_fits` (skips the previous fact). `GameState._report_fact` emits `ev_fact_answered(key, ok)` once per question: wrong **shot** = false, clean correct = true; collisions never count |

## Constraints

- Exit battle via `root_events.ev_exit_game` with post-battle payload
- Answers: respect `is_hittable()` during entry tween
- Speed ramp / health / question count come from `GameConfig`, not hardcode
- Prefer small `RefCounted` helpers over growing `GameState` further
- Combat controls/HUD must work on Mobile (touch), Steam (KBM), and HTML — no platform-locked input
