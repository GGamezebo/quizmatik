# Menu & navigation

## Layers

1. **Scenes** (Menu/Game/PostBattle) — only via `RootEvents`
2. **Full-screen windows** — only via `WindowStackManager`
3. **Dialogs/overlays** (confirm, pause popup) — NOT on the window stack

## Window stack

- One `WindowStackManager` per menu (under `MenuScene/UI`)
- **Forward:** `ButtonWindowTransition` (button → `open_stacked_window(target)`)
- **Back:** `ButtonWindowBack` (button → `close_stacked_window`) or `ui_cancel`
- Never “Back → open MainMenu”; always **pop** so nested paths work (`Main → Levels → LevelSelect`)
- Optional hooks on window scripts: `on_window_enter()` / `on_window_exit()`
- Lazy windows: every menu window except `MainMenuWindow` / `LevelsWindow` is a `LazyWindow` placeholder in `menu.tscn` (`core/lib/window_stack_manager/lazy_window.gd`: `scene` = window `.tscn` uid, instantiated as child `content` on first show, `hidden_content_nodes` = its own `Background`, `preload_delay_sec` 3 = threaded background load, threaded builds only; lab / parents never preloaded). Never `instance=` a window into `menu.tscn` or point a NodePath into a window from outside: buttons inside → `ButtonWindowTransition` / `ButtonWindowBack` `lazy_window` + `lazy_button_path` (path from content); window method after opening → transition `enter_method` (hangar `open_on_planes`); other hooks → `menu.gd` on `LazyWindow.ev_loaded` (training / lab `start_battle_button`, parents `windows_stack_manager`). Window scenes need a header uid generated by Godot (`ResourceUID.id_to_text(ResourceUID.create_id())` / editor save), never hand-typed — Godot can reject a typed one (filesystem cache id -1) → export can't resolve it → empty placeholder with no back button. Code that touches a window = `(lazy as LazyWindow).load_content()`
- Keep `theme = style.tres` on each window root `Control`

## Game start

- Campaign: `{ "battle_info": GameConfig.BattleInfo(...) }`
- Training: `{ "custom_battle": GameConfig }`
- Return: `ev_return_to_menu` (optional `{ "open_level_select": container_id }` → Menu opens pack level grid)
- Quit battle: `ev_exit_game`

## Avoid

- Second navigation stack/router beside `WindowStackManager`
- Loading `GameScene` from menu scripts directly
- Putting confirm/pause dialogs on the full-screen stack
- Building window UI trees in GDScript
