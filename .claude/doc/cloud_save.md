# Облачное сохранение (Yandex Games + Google Play)

Локальный файл остаётся главным; платформенное облако — копия для переноса прогресса между устройствами и после переустановки.

## Как работает

- Игра (`SaveManager`) знает только `PlatformServices`; облако подключают платформенные состояния HFSM: `Yandex/YandexCloudSave` и `GooglePlay/GooglePlayCloudSave`.
- При запуске, когда облако стало доступно, игра один раз запрашивает облачную копию. Побеждает **более новая** (`saved_at`). Если в облаке новее — профили подменяются, если локальная новее — она отправляется в облако. Свежая установка берёт облако.
- Отправка в облако: не чаще раза в 30 с, а при конце боя / сворачивании / закрытии — сразу.
- Если облако не ответило (ошибка, нет сети, нет входа) — игра работает локально и **ничего не отправляет**, чтобы не затереть облако.
- Настройки (язык, звук) в облако не уходят. Тестовая кнопка «СБРОСИТЬ ПРОГРЕСС» в лаборатории сбрасывает только локальный файл — облако вернёт прогресс при следующем запуске.

## Yandex Games

Ничего настраивать не нужно: используется `player.getData/setData` (ключ `save`, лимит 200 КБ). Для неавторизованных игроков данные хранятся на устройстве SDK.

## Google Play (нужны ручные шаги)

1. Установить плагин [godot-play-game-services](https://github.com/godot-sdk-integrations/godot-play-game-services) в `addons/` и включить его; нужна Gradle-сборка (она уже нужна для Play Billing).
2. В экспорт-пресетах `Android` / `Android-Test` указать Game ID плагина (`godot_play_game_services/game_id`).
3. В Play Console → Play Games Services создать игру, привязать приложение и **включить «Сохранённые игры»** (Saved Games).
4. Код вызывает плагин по имени синглтона `GodotPlayGameServices` и методам `isAuthenticated`, `signIn`, `loadGame`, `saveGame` (имена взяты из исходников плагина v3, **не проверены на реальном устройстве**). Если версия плагина другая — поправить константы в `google_play_cloud_save_context.gd`.
5. Без плагина или без входа в Play Games проект собирается и работает, сохранение остаётся локальным.
