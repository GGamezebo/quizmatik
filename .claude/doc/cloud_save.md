# Облачное сохранение (Yandex Games + CrazyGames)

Локальный файл остаётся главным; платформенное облако — копия для переноса прогресса между устройствами и после переустановки.

## Как работает

- Игра (`SaveManager`) знает только `PlatformServices`; облако подключают платформенные состояния HFSM: `Yandex/YandexCloudSave` и `CrazyGames/CrazyGamesCloudSave`.
- При запуске, когда облако стало доступно, игра один раз запрашивает облачную копию. Побеждает **более новая** (`saved_at`). Если в облаке новее — профили подменяются, если локальная новее — она отправляется в облако. Свежая установка берёт облако.
- Отправка в облако: не чаще раза в 30 с, а при конце боя / сворачивании / закрытии — сразу.
- Если облако не ответило (ошибка, нет сети, нет входа) — игра работает локально и **ничего не отправляет**, чтобы не затереть облако.
- Настройки (язык, звук) в облако не уходят. Тестовая кнопка «СБРОСИТЬ ПРОГРЕСС» в лаборатории сбрасывает только локальный файл — облако вернёт прогресс при следующем запуске.

## Yandex Games

Ничего настраивать не нужно: используется `player.getData/setData` (ключ `save`, лимит 200 КБ). Для неавторизованных игроков данные хранятся на устройстве SDK.

## Google Play — облака нет (решение 2026-10-31)

Облако через Play Games «Сохранённые игры» убрано совсем (состояние `GooglePlayCloudSave` и его скрипт удалены). Прогресс на Android хранится только на устройстве.

Почему:

- **«Безопасность данных».** Play считает сбором любую передачу данных с устройства, в том числе через SDK. Play Games Services сам по себе автоматически отправляет аналитику и диагностику, а сохранённые игры — это прогресс на серверах Google. Ответ «данные не собираем» стал бы неправдой.
- **Детская политика.** В играх только для детей допустимы лишь API / SDK, одобренные для детской аудитории; явного разрешения для Play Games нет. Ребёнку без профиля Play Games (нужно согласие родителя в Family Link) показывалось бы окно входа Google — лишний риск для Teacher Approved.

Если перенос прогресса на Android понадобится — делать без аккаунтов и без серверов Google (например, код переноса), и заново сверить анкету «Безопасность данных».
