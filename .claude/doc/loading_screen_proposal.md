# Новый loading screen — «Взлёт»

Статус: реализован вариант **A** (2026-10-03). Отличия от плана: пример — случайный (`MathFact`), без звука улёта; шлейф — точки (`PlaneFlyerTrail._draw`), не `Line2D`; клетка — процедурный шейдер `notebook_grid.gdshader`.

## Что сейчас не так

- `src/ui/loading_screen/` — серый (grayscale-шейдер) акварельный фон с чужим красным бипланом, надпись **«Loading...»** по-английски, стандартный `ProgressBar`. Это выбивается из стиля «карандаш по тетради» и не связано с игроком.
- Уход экрана — случайный поворот ±45° + уменьшение. Выглядит как «уронили лист».

## Идея

Экран — **лист из тетради в клетку** поверх неба. В центре летит **самолёт игрока** (экипированный, с его цветом), за ним рисуется карандашный пунктир. Внизу — «заправка» вместо прогресс-бара и пример на сегодня.

```
┌──────────────────────────────────────────────┐
│  клетчатая бумага, мягкое небо classic_sky    │
│                                                │
│      · · · · · ·   ✈ (самолёт игрока, пламя)   │
│   пунктир-шлейф        покачивается вверх/вниз │
│                                                │
│            «Заводим мотор…»                    │
│   [■■■■■■■□□□□]  ← карандашная линейка         │
│            «А ты знаешь? 7 × 8 = 56»           │
└──────────────────────────────────────────────┘
```

### Анимация самолёта

1. **Появление (0.3 с):** самолёт влетает слева в центр (`TRANS_BACK`, `EASE_OUT`).
2. **Ожидание (цикл):** плавная синусоида по Y (амплитуда ~18 px, период ~1.6 с). Кадр атласа меняется по направлению движения — `up` / `idle` / `down`, как в бою; наклон ±2°; пламя (`flame.png`) мерцает. Лёгкий `PositionShaker` для «живости».
3. **Шлейф:** `Line2D` с пунктирной карандашной текстурой — точки хвоста за соплом, затухание по длине.
4. **Уход (`fade_out`, ~0.6 с):** самолёт разгоняется вправо за экран, шлейф вытягивается, затем лист уезжает вверх (текущий slide `offset:y` оставляем, случайный поворот убираем). Опционально — `victory_whoosh.wav`.

### Прогресс

- Вместо `ProgressBar` — полоска-«линейка» в стиле тетради (cream + graphite, `TextureProgressBar` с 2 текстурами). Значение — `lerp` к целевому, чтобы не прыгало (на HTML5 без потоков загрузка часто идёт рывком 0 → 1).
- Текст по-русски: «Заводим мотор…» / «Проверяем крылья…» / «Взлетаем!» (по порогам прогресса).
- Нижняя строка — случайный простой пример («7 × 8 = 56»). Учебно и в духе игры; список фраз — в `.tres` экрана.

### Цвет самолёта

Тот же атлас `planes_atlas_spaced.png` + `tint` из `PlaneCatalog.get_def(id)` — как в ангаре.

## Платформы

- Мобильные / браузер: только `Tween` + 1 атлас + `Line2D`, без тяжёлых шейдеров. Ввод не нужен.
- Экран показывается при входе в **меню** и **бой** (`app_hfsm.json` → `loading_screen: true`); самолёт — один и тот же, равный экипированному.

## Варианты на выбор

- **A (рекомендую):** самолёт парит в центре, прогресс — линейка снизу. Хорошо смотрится при любой скорости загрузки.
- **B:** самолёт летит слева направо по пунктирной трассе, позиция = прогресс. Нагляднее, но при мгновенной загрузке самолёт «телепортируется» — нужна плавная подтяжка и минимальное время.
- **C:** как A, но при входе в бой рядом мелькают 2–3 воздушных шарика с числами (намёк на предстоящий бой). Больше работы, нужен payload «куда грузимся» — сейчас loading screen его не получает.
