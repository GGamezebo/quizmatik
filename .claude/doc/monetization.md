# Квизматик: монетизация

Обновлено: 2026-10-09. Статус: **реализовано в коде** для Яндекс Игр и Google Play. Осталось настроить консоли магазинов (см. ниже).

## Главная идея
Играет ребёнок 7–10 лет, платит родитель. Поэтому продаём **доступ к контенту и отсутствие рекламы**, а не валюту и не преимущество в бою.

Никогда:
- не продавать золото / пакеты валюты, лутбоксы, «энергию», таймеры ожидания;
- не продавать то, что помогает в бою (скорость, прицел, жизни) — косметика остаётся только внешним видом;
- не прятать за рекламой или оплатой обучение, подсказки, «работу над ошибками»;
- не показывать рекламу во время решения примеров.

Всегда:
- покупка — за родительским барьером (пример «двузначное × двузначное» с 4 вариантами);
- одна понятная покупка вместо магазина с десятком товаров.

## Модель по платформам

| Платформа | Бесплатно | Реклама | Покупка |
|---|---|---|---|
| Яндекс Игры | Все долины | Interstitial между боями + rewarded «+🪙» | «Без рекламы» — **199 ₽** (отключает interstitial) |
| Google Play | Долина сложения, практика, задания дня | Нет | «Полная версия» — **$2.99** (остальные долины) |
| Steam (позже) | — | Нет | Премиум, без покупок внутри |

Важно для России: оплата Google Play в России не работает. Если понадобится русская аудитория на Android — отдельная ветка `Android/RuStore` (та же схема, новый контекст).

## Реклама (Яндекс)

**Interstitial:**
- только при возврате в меню между боями;
- не раньше 3-го боя за сессию;
- не чаще раза в 3 минуты;
- после покупки «Без рекламы» — никогда.

**Rewarded «+🪙 за рекламу»:**
- экран после боя (победа и поражение): удваивает заработанное золото, минимум +1, максимум +5; один раз на экран;
- ангар: +1 🪙, можно повторять;
- лимит 5 просмотров в день на устройство (общий для всех пилотов — нельзя фармить сменой профиля);
- остаётся и после покупки «Без рекламы» — его смотрят добровольно.

## Где что видно игроку
- Экран после боя — кнопка «+N за рекламу» в правом нижнем углу.
- Ангар — кнопка «+1 за рекламу» под счётчиком золота.
- Настройки — кнопка «Убрать рекламу» (Яндекс) или «Полная версия» (Play) под окном.
- Карусель долин (Play) — платные долины с замком и жёлтой плашкой «Полная версия»; тап открывает окно покупки.

## Сборки для тестеров — без монетизации
Монетизация поднимается только как отдельное состояние HFSM рядом с платформой (`Yandex/YandexShop`, `GooglePlay/GooglePlayShop`). Единый выключатель — фича экспорта **`no_monetization`**: с ней магазин не открывается, игровая часть монетизации не загружается, все долины открыты, кнопок рекламы и покупок нет.

| Пресет | Для кого | Монетизация |
|---|---|---|
| `Web` | тестеры (itch.io / GitHub Pages) | нет |
| `Web-Yandex-Test` | тестеры в черновике Яндекса (SDK работает) | нет (`no_monetization`) |
| `Android-Test` | тестеры Android (`com.quizmatic.app.test`) | нет |
| `Web-Yandex` | релиз Яндекс | есть |
| `Android` | релиз Google Play | есть |

Отключить монетизацию в любой сборке: добавить `no_monetization` в Custom Features пресета.

Проверка в редакторе без магазина: Project Settings → Run → Main Run Args: `-- --dev-shop=yandex` или `-- --dev-shop=play` — поднимется фейковый магазин (реклама «длится» 0.6 с, покупка всегда успешна).

## Что настроить перед релизом

**Яндекс Игры (консоль разработчика):**
1. Консоль → Профиль: проверить статус «Единая лицензионная схема»; если покупки не подключены — отправить заявку на подключение (юрлицо/ИП: один договор на рекламу и покупки; самозанятый: договор на покупки как физлицо).
2. Консоль → Игры → твоя игра → Инап-покупки → Инапы → «Добавить инап»: ID **`no_ads`** (в точности, как в `yandex_shop_context.gd`), «Стоимость в янах» **199** (проверить курс в разделе «Курс портальной валюты»), «Название» на русском и английском («Без рекламы» / «No ads»), описание до 200 символов, иконка 256×256 PNG.
3. Инап-покупки → Настройки → «Список логинов для тестовых покупок»: добавить свой Яндекс ID (тестовые покупки бесплатны).
4. Экспорт пресетом `Web-Yandex`, загрузить архив во вкладку «Черновик» и отправить на модерацию (обычно 3–5 рабочих дней). После одобрения статус станет «Покупки подключены».
5. Проверка незавершённых покупок при запуске (`getPurchases`) уже есть в `YandexShopContext` — она обязательна для модерации.

**Google Play:**
1. Скачать плагин GodotGooglePlayBilling (github.com/godot-sdk-integrations/godot-google-play-billing) в `addons/GodotGooglePlayBilling/`, включить в Project Settings → Plugins.
2. В пресете `Android` включить `gradle_build/use_gradle_build`, установить Android build template.
3. В Play Console создать разовый товар (one-time product) с ID **`full_version`**, базовая цена $2.99.
4. Заполнить анкету Families / целевая аудитория, политику конфиденциальности.
5. Покупки проверяются только на сборке, загруженной в Play (внутреннее тестирование).

Без плагина игра собирается и работает: магазин просто молчит, все долины открыты.

## Порядок дальше
1. Раздать тестерам `Web` / `Web-Yandex-Test` / `Android-Test`.
2. Выпуск на Яндексе, смотреть D1/D7 и доход с рекламы.
3. Отчёт для родителя — аргумент для покупки «Полной версии».
4. Google Play с «Полной версией».
5. При необходимости RuStore, Steam.
