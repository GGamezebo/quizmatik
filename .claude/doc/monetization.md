# Квизматик: план монетизации

Дата: 2026-10-08. Статус: план, в коде пока есть только контракт `PlatformServices` и реклама в `YandexContext` (UI для неё ещё нет).

## Главная идея
Играет ребёнок 7–10 лет, платит родитель. Поэтому продаём **доступ к контенту и отсутствие рекламы**, а не валюту и не преимущество в бою.

Никогда:
- не продавать золото / пакеты валюты, лутбоксы, «энергию», таймеры ожидания;
- не продавать то, что помогает в бою (скорость, прицел, жизни) — косметика остаётся только внешним видом;
- не прятать за рекламой или оплатой обучение, подсказки, «работу над ошибками»;
- не показывать рекламу во время решения примеров.

Всегда:
- покупка и внешние ссылки — за родительским барьером (простая задачка «для взрослых»);
- реклама — только неперсонализированная, для детской аудитории;
- одна понятная покупка вместо магазина с десятком товаров.

## Модель по платформам

| Платформа | Модель | Что продаём |
|---|---|---|
| Яндекс Игры | Бесплатно + реклама | Interstitial между боями, rewarded «+🪙». Позже — покупка «Без рекламы» через Yandex Payments |
| Android (RU) | Пробная часть + одна покупка | RuStore: «Полная версия» (все долины + без рекламы). Реклама — Yandex Mobile Ads |
| Android (мир) | То же | Google Play Billing: «Полная версия». Реклама — только Families-сертифицированная |
| Steam / ПК | Премиум | Платно один раз, без рекламы и покупок; ачивки Steam |

Важно для России: оплата через Google Play и реклама Google (AdMob) в России не работают. Для русской аудитории на Android нужны RuStore + Yandex Mobile Ads; Google Play — для англоязычной аудитории.

Ориентиры цен (проверить по конкурентам перед релизом): «Полная версия» 299–399 ₽ / $2.99–4.99; Steam $3–5.

## Что бесплатно, что платно (мобильная версия)
- Бесплатно: вся долина сложения (включая экзамен), практика, задания дня, профили, косметика за золото.
- «Полная версия»: остальные долины (вычитание, умножение, деление, смесь) + отключение interstitial.
- Rewarded-реклама остаётся и после покупки — её смотрят добровольно.

На Яндексе все долины бесплатны, деньги дают реклама и (позже) «Без рекламы».

## Реклама

**Interstitial** (основной доход на Яндексе):
- только при возврате в меню между боями;
- не в первые 3 боя нового игрока;
- не чаще раза в 3 минуты;
- никогда во время боя, обучения и сразу после первого прохождения экзамена (праздничный экран).

**Rewarded «+🪙 за рекламу»**:
- экран после боя (и победа, и поражение): награда `max(1, золото_за_бой)`, один раз на экран;
- ангар: «Не хватает N 🪙 → посмотреть рекламу» (+1 🪙);
- общий лимит 5 просмотров в день на устройство (не на пилота — иначе фарм через профили);
- кнопка видна только если платформа сообщила `can_rewarded`.

**Позже, по метрикам:** «Продолжить бой» за рекламу при поражении.

## Тестовые сборки — без монетизации
Монетизация появляется **только** когда поднимается контекст магазина в HFSM (`Yandex`, `GooglePlay`, `RuStore`, `Steam`). Его включает фича экспорта (`yandex_games`, `google_play`, …).

Сборки для тестеров — пресеты **без** фич магазина:
- `Web` → `bin/index.html` (выложить на itch.io / GitHub Pages с паролем);
- `Android-Test` → `bin/quizmatik_test.apk`, пакет `com.quizmatic.app.test` (ставится рядом с релизной версией).

В них `PlatformServices` остаётся по умолчанию: нет рекламы, нет кнопок «за рекламу», нет покупок, **все долины открыты**. Ничего переключать вручную не нужно, и нельзя случайно забыть выключить.

Правило для кода: любой рекламный/платный элемент UI показывается только по флагу из `PlatformServices`; закрывать контент может только контекст магазина. По умолчанию — «всё доступно, ничего не продаётся».

## Порядок работ
1. **Тестеры** — сейчас, сборки `Web` / `Android-Test`. Собрать отзывы о первых минутах, балансе, обучении.
2. **Яндекс: реклама** — interstitial между боями + rewarded после боя и в ангаре. Первые деньги и метрики (D1, D7, % прохождения обучения).
3. **Отчёт для родителя** — аргумент для покупки и для хороших отзывов.
4. **Android: «Полная версия»** — сначала RuStore или Google Play (решить по основной аудитории), родительский барьер, восстановление покупки.
5. **Яндекс: «Без рекламы»** через Yandex Payments.
6. **Steam** — премиум-сборка.
7. **Подписка** — только когда будет регулярный новый контент (новые долины, отчёты); не раньше.
